# Tic Tac Toe 🎮

A simple and fun two-player Tic Tac Toe game built using HTML, CSS, and JavaScript — 
playable directly in the browser with no installations required.

---

## ✨ Features

- 🎮 Two-player mode (X vs O)
- 🏆 Winner announcement on game completion
- 🔄 New Game button to restart anytime
- 🎨 Clean and colorful UI with smooth card-style board
- ⚡ Instant win detection across rows, columns, and diagonals

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Structure | HTML5 |
| Styling | CSS3 |
| Logic | JavaScript (Vanilla) |

---

## 🎯 How to Play

1. Player **X** goes first
2. Players take turns clicking on empty cells
3. First player to get 3 in a row (horizontal, vertical, or diagonal) wins
4. Click **New Game** to reset and play again

---

## ⚙️ How to Run

```bash
# Clone the repository
git clone https://github.com/Tasmiya011/tic-tac-toe-game.git

# Open index.html in your browser
```

No dependencies. No installations. Just open and play!
